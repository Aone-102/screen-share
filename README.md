# 화면 공유 (GitHub Pages 버전)

브라우저에서 여러 명이 같은 방에 들어가 서로의 화면/카메라를 보는 정적 웹앱입니다.
서버 없이 **PeerJS 공용 신호 서버**로 연결을 중계하고, 실제 영상은 참가자 간 **WebRTC P2P**로 전송합니다.

## GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더의 파일을 저장소 **루트**에 업로드합니다.
   - `index.html`, `style.css`, `app.js`, `peerjs.min.js`, `README.md`
   - `peerjs.min.js`는 오프라인에서도 로드되도록 저장소에 포함되어 있습니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Source: Deploy from a branch**, 브랜치 `main`, 폴더 `/ (root)`를 선택하고 **Save**합니다.
5. 잠시 뒤 `https://<사용자명>.github.io/<저장소명>/` 링크가 생성됩니다.

## 사용 방법

- PC와 휴대폰 모두 같은 GitHub Pages 링크로 접속합니다.
- 이름과 방 코드(영문/숫자 3~16자)를 입력합니다.
- **처음 입장한 사람이 방장**이 되고, 이후 참가자는 같은 방 코드로 입장합니다.
- 각자 **화면 공유**(PC) 또는 **카메라**(휴대폰)를 누르면 다른 참가자에게 타일로 표시됩니다.
- 방장이 나가면 방이 종료됩니다.

## 제약

- GitHub Pages는 HTTPS를 제공하므로 화면/카메라 권한은 정상 동작합니다.
- 신호 서버는 **PeerJS Cloud**의 무료 공용 서버입니다. 속도 제한이 있거나 일시적으로 불안정할 수 있습니다.
- 서버가 없으므로 **방장이 나가면 새 참가자가 입장할 수 없고 방이 종료**됩니다.
- TURN 서버가 없어 사내망/공용 Wi-Fi처럼 P2P를 차단하는 네트워크에서는 연결이 실패할 수 있습니다.
- 휴대폰 브라우저는 화면 전체 공유(`getDisplayMedia`)를 지원하지 않아 **카메라 공유**로 참여합니다.
- 한 방 최대 10명이지만, 여러 명이 동시에 공유하면 P2P 연결 수가 많아져 느려질 수 있습니다.

## 더 안정적으로 운영하려면

`screen-share-github`의 Node.js 버전을 Node.js + WebSocket을 지원하는 호스팅에 배포하면
자체 신호 서버와 방장 없는 룸을 사용할 수 있습니다. GitHub Pages는 정적 파일만 호스팅하므로
Node.js 서버를 직접 실행할 수 없습니다.
